**التكليف:** سؤال مالك 2026-11-22 ~03:36 («راجعت الأدوات اللي هو قال عليها؟») عبر المدير · **النطاق:** ٣٠ أداة وردت في جدول فحص ما قبل الإنتاج وترشيحات Gemini · **المرجع:** ستاك الشركة الحقيقي (React+TS+Supabase+Vercel+PWA، GitHub Actions، صفر سيرفر مدفوع) واللي شغال فعليًا · **التفاصيل:** `A-testing.md` · `B-security.md` · `C-perf-a11y.md` · `D-ops.md` (بحث ويب حي، مصادر رسمية أولًا، نوفمبر 2026)
