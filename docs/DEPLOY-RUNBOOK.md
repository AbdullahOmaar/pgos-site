**الحالة:** محجوب حاليًا — أدوات Vercel المتصلة ترفض نطاق فريق الحساب (403: scope `thepresidentabdo-9110s-projects` يحتاج إعادة تفويض من صاحب الحساب؛ أداة توليد رابط التفويض غير متاحة في مجموعة الأدوات المراجعة). صُعّد للمدير 2026-11-22 ~03:12. **لا يُنشر أي شيء قبل فكّه.**

## التسلسل الملزم (لا يتغير ترتيبه)

1. **بناء مُنقّى فقط:** `npm run data:sanitize && npm run build` — التحقق قبل الرفع: البحث في `dist/data/site-data.json` عن `3A-316|L-0017|TOTO-001` = صفر نتائج، ووجود DEMO.
2. **إنشاء مشروع Vercel** باسم `pgos` (فريق thepresidentabdo-9110s-projects) بالإعدادات في `vercel.json` (Vite، إخراج dist، SPA fallback، ترويسات أمان + noindex).
3. **البوابة = خزنة التشفير (قرار مقر ٩، 2026-11-22):** حماية Vercel Authentication للإنتاج غير متاحة على خطة Hobby (بحث 3A-315 الموثق) — البوابة المعتمدة هي خزنة E2EE المحصودة من pgos-app: البيانات الحقيقية تُشفّر محليًا (AES-256-GCM، DEK مغلف لكل جهاز مالك مسجل بـECDH P-256 + HKDF) ولا يوجد على الخادم إلا نص مشفر. تفعيل الجهاز يحدث بعد نشر المُنقّى (الخطوة ٤).
4. **نشر المُنقّى** ورفعه. المالك يفتح الرابط من جهازه → شاشة التفعيل تولّد مفتاح الجهاز ويظهر **كود التفعيل العمومي** → يرسله المالك في الشات → يُسجّل في `tools/devices.json`.
5. **إثبات الرفض (دليل القبول):** طلب الرابط/اللقطة بلا جهاز مسجل — لازم النتيجة شاشة تفعيل فقط ونص مشفر عند جلب `snapshot.enc.json`، ويتوثق في سجل أدلة PGOS جديد (EVD) + تعليق على 3A-316. **لو ظهرت أي بيانات مقروءة بلا جهاز مسجل: إيقاف فوري وحذف النشر — لا متابعة.**
6. **النشر الحقيقي خلف البوابة:** `npm run data && npm run data:encrypt && npm run build` (بيانات حقيقية مشفرة لجهاز المالك المسجل) ثم النشر، وإعادة إثبات الرفض بلا جهاز + إثبات الفتح وفك التشفير على جهاز المالك.
7. **تحقق حي:** فتح الموقع من جلسة المالك، فحص الصفحات الـ١٥، أختام الحداثة، وحالة السلسلة/التحقق — النتائج في EVD + قيد سجل إنجاز.
8. **قرار المالك (محفوظ):** الإعلان/الإطلاق العام وتقاعد لوحة «مركز متابعة عبدالله» — بعد رؤية الموقع حيًا فقط.
