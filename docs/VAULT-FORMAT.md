# صيغة خزنة اللقطة المشفرة — PGOS Vault Format v1

تنفيذ واحد مشترك: `src/lib/vault.mjs` (يعمل في المتصفح وفي Node — المزامنة والاختبار والموقع يستخدمون نفس الكود حرفيًا).

## الحزمة (snapshot.enc.json)

```json
{
  "v": 1,
  "alg": "P256-ECDH+HKDF-SHA256+A256GCM",
  "created_at": "<ISO>",
  "payload": { "iv": "<b64u 12B>", "ct": "<b64u>" },
  "wraps": [
    { "device": "<id>", "fp": "<fingerprint>", "eph": "<b64u raw P-256 pub 65B>", "iv": "<b64u 12B>", "ct": "<b64u 48B>" }
  ]
}
```

## الخوارزمية

- **DEK**: ‏32 بايت عشوائية لكل لقطة. الحمولة = JSON اللقطة مضغوطًا (UTF-8) مشفرًا بـ AES-256-GCM تحت DEK وIV عشوائي.
- **تغليف لكل جهاز** (ECDH + HKDF + AES-GCM):
  1. مزامنة: زوج مفاتيح ECDH P-256 مؤقت (ephemeral) لكل جهاز.
  2. السر المشترك = `ECDH(ephemeral_priv, device_pub)` — أول 256 بت (إحداثي X) عبر WebCrypto `deriveBits`.
  3. ‏KEK = ‏HKDF-SHA256(ikm=shared, salt=raw ephemeral public key bytes, info=`"pgos/v1/dek-wrap"`, L=32) كمفتاح AES-GCM.
  4. ‏`ct` = AES-256-GCM(KEK, iv عشوائي) على الـ DEK الخام.
- **فك التغليف** (المتصفح): بمفتاح الجهاز الخاص (IndexedDB، غير قابل للاستخراج، استخدام `deriveBits` فقط) يعيد الخطوات عكسيًا: ECDH مع `eph` ← HKDF بنفس المعاملات ← فك DEK ← فك الحمولة.
- **بصمة الجهاز** `fp`: أول 10 بايت من SHA-256 للمفتاح العمومي الخام، بصيغة hex مجمعة (xxxx-xxxx-…). تُستخدم لمطابقة التغليف المناسب للجهاز وعرضًا للمالك.
- **كود التفعيل**: المفتاح العمومي الخام (65 بايت) بـ base64url — يُنسخ من شاشة التفعيل ويُسجّل في `sync.devices.json` عند خط الأنابيب. الكود العمومي ليس سرًا.

## قواعد صارمة
- لا يُخزّن المفتاح الخاص خارج IndexedDB الجهاز، ولا يُرسل شبكيًا أبدًا.
- استيراد مفتاح خاص بـ JWK متاح فقط كمسار «استعادة جهاز» صريح داخل شاشة التفعيل (وللاختبار الآلي برأسيات واضحة).
- أي فشل فك تشفير = حالة خطأ صريحة في الواجهة، لا بيانات جزئية.
