# دفتر تشغيل يوم الإطلاق — موقع PGOS (3A-316)

**الغرض:** الخطوات المرتبة بالضبط ليوم النشر والإطلاق، جاهزة للتنفيذ دون تحضير إضافي. كل خطوة مالك موضحة كذلك. **لا تُنفذ أي خطوة شراء/دومين/ترقية خطة هنا** — خارج النطاق المحفوظ.

## قبل اليوم (مكتمل بالفعل — لا يُعاد)

- البناء المُنقّى مُتحقق منه (٠ معرفات، ٤٠ DEMO) · البناء المشفر جاهز (`build:encrypted`) · الخزنة مثبتة ومراجعة مستقلًا · CI مظبوط (لكن تشغيله معلق بفوترة GitHub — عنصر مالك منفصل لا يمنع النشر اليدوي)

## تسلسل اليوم

### ١) خطوة المالك — منح وصول فريق Vercel
المالك يمنح تطبيق Vercel وصول فريق `thepresidentabdo-9110s-projects` (من لوحة الفريق أو إعادة الربط من التطبيق). يتحقق الوكيل بعدها فورًا: `get_git_deployment_context` يعيد الفريق غير فارغ. **بدونها لا نشر** — ويستمر باقي العمل حولها.

### ٢) نشر المُنقّى
`npm run data:sanitize && npm run build` ثم نشر `dist/` على مشروع `pgos` الجديد بإعدادات `vercel.json`. يتحقق الوكيل: الرابط يفتح شاشة تفعيل الخزنة فقط.

### ٣) خطوة المالك — تفعيل جهازه
المالك يفتح الرابط من هاتفه → شاشة التفعيل تولّد مفتاح الجهاز → يرسل **كود التفعيل العمومي** في الشات. الوكيل يسجله في `tools/devices.json` (مفتاح عمومي فقط — ليس سرًا).

### ٤) النشر الحقيقي المشفر
`npm run data && npm run data:encrypt && npm run build:encrypted` ثم نشر `dist/` (يحوي `snapshot.enc.json` فقط — الواضح محذوف آليًا). يتحقق الوكيل: جلب اللقطة بلا جهاز = نص مشفر فقط.

### ٥) إثبات الرفض حيًا (دليل القبول)
- بلا جهاز مسجل: الرابط يعرض شاشة تفعيل فقط؛ `snapshot.enc.json` نص مشفر (0 معرفات).
- على جهاز المالك: الموقع يفتح ويفك التشفير ويعرض الصفحات الـ١٦ + أختام الحداثة + حالة السلسلة.
- النتائج: سجل أدلة PGOS جديد (EVD) + تعليق على 3A-316 + قيد سجل.

### ٦) خطوتا المالك — قرارا الإطلاق
بعد رؤية الموقع حيًا، المالك يقرر: (أ) الإعلان/الإطلاق العام، (ب) تقاعد لوحة «مركز متابعة عبدالله» كواجهة أساسية. كل قرار يُسجل في سجل قرارات المقر قبل تنفيذه.

## التراجع (Rollback)

- **قبل الخطوة ٤:** حذف نشر المُنقّى من Vercel — لا بيانات حقيقية كانت عليه أصلًا.
- **بعد الخطوة ٤:** حذف النشر + إعادة تشفير لقطة جديدة (DEK جديد لكل لقطة) إن اشتبه في أي تسرب؛ المفاتيح الخاصة بالأجهزة لا تتأثر (التغليف يعاد فقط).
- **أي ظهور بيانات مقروءة بلا جهاز مسجل في أي لحظة:** إيقاف فوري وحذف النشر — لا متابعة.
